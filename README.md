\# Пёс Борис



Локальная страница компании ДогЯндекс для ведения учета кормления и прогулок пса Бориса



\## Назначение



Отслеживание регулярности прогулок и кормления пса Бориса, а также бронирование временных слотов для выгуливания пса



\## Локальный запуск



Запустите сервер командой `npm start` и откройте http://localhost:3000. Проверка синтаксиса выполняется командой `npm run build`.



\## Ограничения



Сайт сохраняет один самодостаточный `index.html` со встроенными HTML, CSS и JavaScript. `server.js` использует только встроенные `node:http`, `node:fs` и `node:path`, запоминает введенные значения и использует базу данных SQLLite, не использует внешние запросы. Регистрации, авторизация, роли пользователей, личные кабинеты отсутствуют;



\## Готовность



\- Сервер запускается на http://localhost:3000 без установки пакетов.

\- Видны шапка, текущая дата, пять слотов прогулок, свободные и занятые слоты различаются, а у занятого слота видно ФИО.

\- Слоты и их состояния бронирования загружаются через `GET /api/timeslots` и содержат пять слотов на текущую дату.

\- Визуально применен тёплый светло-фиолетовый фон, нежно-оранжевый основной цвет и крупная графика.

\- Бронирование слота отправляется через `POST /api/reservation`, выделяет забронированный слот и показывает подтверждение и ФИО забронировавшего.
